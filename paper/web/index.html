The Output Budget Confound

Why token ceilings silently decide LLM planning benchmark results

SlotSaver TeamSteelHacks 2026Preprint

Comparisons between language models on planning benchmarks are usually reported as a single accuracy number per model. We show that for models which reason in the open, this number is not a property of the model alone. It is jointly determined by the output token ceiling the evaluator happened to choose.

On the Calendar Scheduling task of NATURAL PLAN, raising the ceiling from 512 to 4096 tokens moves Nemotron Super from 1.5% to 84.7% with the prompt, the sample and the scoring held fixed. The model was not failing to plan. At the lower ceiling 98.5% of its generations were cut off before an answer existed, and an exact match scorer recorded that truncation as a planning error.

The finding

Planning under constraints is an attractive evaluation target because solutions are hard to find and cheap to verify. NATURAL PLAN scores a proposed meeting time by exact match against a golden answer, with no human annotation and no model acting as judge. That is why we chose it: it removes the failure mode where the party reporting a comparison also authored its ground truth.

Having removed that confound, we hit another. Models differ sharply in how much text they emit before committing to an answer. A model that reasons silently answers in tens of tokens; one that reasons in the open may spend thousands. Every harness imposes a generation ceiling. When that ceiling falls below what a model needs to finish, the harness records no answer, and an exact match scorer cannot tell an absent answer from a wrong one.

How we found it

Our first run scored Nemotron at 0 out of 12. Reading the raw generations showed the model mid derivation at the cut, having already correctly enumerated every participant constraint. Had we trusted the number instead of the text, we would have published a false result in good faith, and the harness, not the model, would have been at fault.

Nemotron's headline accuracy ranges across 83 percentage points as the ceiling moves. Its conditional accuracy, computed over only the generations allowed to finish, stays between 85.7% and 100% throughout. The headline number is measuring the harness, not the model.

Detecting truncation is harder than it looks

The obvious check is to compare the emitted token count against the ceiling. That test is wrong for any model reasoning in hidden tokens, and it fails in the direction that makes a model look worse.

Instrumenting the vendor's full token accounting shows why. At a ceiling where it runs to completion, Gemini 3.5 Flash emits 21 visible tokens per item while spending 1,344 reasoning tokens absent from that count. True generation spend is roughly 65 times what the output token field reports.

ceiling 512, visible output tokens: 21    -> naive check: not truncated
              hidden thinking tokens: 1344  -> real spend: ~1365 tokens
                                                512 cannot hold it

Truncation at 512 is therefore not merely possible, it is arithmetically unavoidable. The raw generations agree: 'Here is the proposed time: Monday, 12:00 - 1', cut mid answer, while the field an evaluator would naturally check reported no truncation at all. We take the vendor's finish reason as authoritative and treat any token based rule as a fallback.

What separates the models: not much

The result we did not want

At a matched ceiling, exact McNemar tests on paired per item outcomes separate none of the model pairs. Nemotron against Claude is 10 versus 7 discordant items out of 59 paired. We report this because an earlier version of our own analysis counted provider rate limit errors as wrong answers and produced a confident p < 0.0001 that was entirely infrastructure noise.

Run to run variation reinforces the caution. Nemotron at temperature zero scored 98.3% of items identically across two independent seeded runs. Claude, which we could not pin to temperature zero because its SDK no longer exposes the parameter, agreed on only 62.5%. A single accuracy figure for a model at a nondeterministic temperature is a draw from a distribution whose spread is not small.

What we recommend

The fix is small and cheap. Evaluation reports should state the generation ceiling alongside accuracy, and verify it binds on no model before comparing any two. One statistic suffices: the fraction of generations that terminate at the ceiling rather than at a stop token. A model whose truncation rate is materially above zero has not been measured, it has been cut off, and its accuracy carries no information about its planning ability.

This interacts badly with two current trends. Models increasingly reason in the open or in hidden tokens, and harnesses increasingly cap output to control cost. Those pressures push in opposite directions, and the resulting headline number is quietly sensitive to a parameter that is rarely reported at all.

Contributions

  1. The generation ceiling isolated as an experimental variable on an established benchmark, moving one model across 74 accuracy points.
  2. Truncation rate and conditional accuracy as reporting statistics that separate planning failure from harness failure.
  3. Evidence that the obvious truncation check is unsound for models reasoning in hidden tokens, with the 65x under-report measured.
  4. Accuracy reported jointly with output spend and latency, on a scorer validated against published numbers before any comparison.
  5. Run to run variance quantified from a seeded replication.

Limitations

Contamination is not controlled. NATURAL PLAN has been public since 2024 and may appear in any of these models' training data. Exposure is symmetric across models, and the headline result is a within model effect, but we make no decontamination claim.

Sample loss correlates with the swept variable. The provider returned 429 and 503 at a rate rising with the ceiling, because larger ceilings mean longer generations and more concurrent requests. Higher ceiling cells therefore rest on fewer retained items. A dropped call produced no output at all, independent of whether that output would have been correct, so we do not believe this biases direction, but it costs precision exactly where we would most want it.

Scope. One task, one benchmark, two models in the primary comparison. Gemini results are preliminary: its free tier permits twenty requests per day for that model, which is not a sample size.

Reproducing this

python scripts/run_naturalplan.py --per-bucket 10 --shots 5 \
    --max-tokens 512 1024 2048 4096 --models nemotron claude
python scripts/make_figures.py      # figures, tables, every quoted number
python scripts/check_paper.py       # static check before submission

Scoring reproduces the behaviour of the official evaluator from the benchmark repository. We validated it before running anything: it scores the reference predictions shipped with the dataset at 48.9%, against 48% reported in the original work. Sampling is seeded and stratified by participant count, because the raw set is half two participant items and a uniform sample would mostly measure the easiest bucket.
